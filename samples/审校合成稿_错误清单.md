# 审校合成稿 — 错误清单与参考答案

配套文件：`审校合成稿.md`（1806 字，4 章，`cut_by=200` 时切 11 块）。

**用途**：作为固定样本反复测试 `proofread max` 全管线，验证
（a）确定性各阶段检出不回归；（b）LLM 阶段在不同 `--chunk-size` 下召回率
不下降；（c）Word/PDF 写回定位不漂移；（d）被跳过/未定位发现可观测
（`*_skipped.json`）。

**确定性阶段**（跑一次即全部命中，`validate_synthetic.py` 自动断言）：

| 阶段 | 数量 | 内容 |

### 1. 边界处错误
| 位置 | 错误 | 期望 |

| 文档首句（块1 头）| "改革開放以来" | 繁體字由 TGSCC 抓；LLM 无需处理 |

### 3. 需要上下文的事实问题（书内自相矛盾，非联网核验）

## 复测方法

```zsh
# 1) 确定性验证（无需 API，秒级）
python3 samples/validate_synthetic.py

# 2) LLM 全管线（同一样本换 chunk-size 对比召回）
proofread m samples/审校合成稿.md --no-view --chunk-size 200 --rpm 60
proofread m samples/审校合成稿.md --no-view --chunk-size 600 --rpm 60
proofread m samples/审校合成稿.md --no-view --chunk-size 800 --rpm 60

# 3) 检查产物
open samples/审校合成稿_max_report.html     # 报告（含被跳过横幅）
cat samples/审校合成稿_max_results.json     # 发现 JSON（stats 含 findings_from_llm / dropped_match）
cat samples/审校合成稿_skipped.json         # 被跳过/未定位清单（若有）
```

对比标准（对齐 Codex 文档 §4.3 / §6.3 门）：
- 上表 5 类 LLM 预期发现**召回不下降**；
- 确定性计数稳定（64 / 5 / 2）；
- P 编号与 `*_skipped.json` 不漂移；
- `*_max_results.json` 的 `stats.phase1` 记录 `findings_from_llm` 与 `dropped_match`，可复核覆盖率。

## 已知限制（本模板 QA 发现）

- **结构检查器对全文正则扫描**：`phase0_structure` 用 `第X章` / `N.` 模式直接
  扫全文，正文若含"在第二章中""12.9亿"这类字样会产生结构误报（章跳号、目编号
  跳到 12/13）。本模板已规避（叙述改用"后文"、数字改中文数字）。**这是检查器
  自身缺陷，真实书稿同样会误报**，建议后续修复为只扫描 markdown 标题行。
- TGSCC 的 `tgscc.py` 含 Windows 硬编码路径（`D:/语文出版社/…`），从项目根
  目录运行时会走 `tgscc_data.json`；改在别处运行可能触达文件系统错误，属既有问题。
