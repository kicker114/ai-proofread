## 《技术垄断》全书 PDF 审校完成（2026-08-05 夜）

- 输入：/Users/kicker114/Downloads/技术垄断-内文.pdf（284页，18.2万字，13页插图无文字层）
- 流程：pdf2md → proofread max（--concurrent 8 --rpm 60，后台阻塞等待）→ annotate
- 审校耗时：1h29m53s（772块 LLM 异步审校，deepseek-v4-flash）
- 发现：TGSCC 3 + 异形词 2 + 结构 170 + LLM 1156 = 1331 条
- 高亮回写：1148 条命中（exact 1048 / crosspage 25 / fragment 75），183 跳过（170 为 structure 无原文字段属正常；13 为单字/未定位）
- 产物：技术垄断-内文_审阅版.pdf（3.3MB，265页含批注，1173 注释）+ _批注清单.csv（313KB）
- 关键经验：
  - 后台任务在本环境回合结束会被回收 → 必须 run_in_background + 同回合内 TaskOutput 阻塞等待，nohup 无效
  - 8 并发 + RPM 60 时瓶颈在 API 单次响应（~7s/块），772 块约 1.5h；3并发则要 4-5h
  - PyMuPDF 1.27 遍历 annots 用 list() 一次性消费，an.next 链式遍历会报 not bound
  - structure 类发现只有 message 无 original 字段 → annotate 天然跳过，属预期行为
